## About This Clone

A front-end recreation of Spotify's web player interface — sidebar navigation, playlist grid, now-playing bar, and the overall dark theme, all built without any framework.

**Focus of this build**
- Matching Spotify's layout and spacing using CSS Grid and Flexbox
- Recreating the sidebar, top navbar, and bottom player bar
- Hover and active states on playlist cards and nav items
- Responsive behavior down to smaller screens
